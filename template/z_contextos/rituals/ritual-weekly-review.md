# Ritual — Weekly Review

**Called by:** `ritual-eow.md`. **Standalone trigger:** "give me a weekly review" / "how was my week".

**Reads:** all of this week's daily journals + completed-vs-planned tasks for the week (tasks with due dates this week; flag anything overdue).

**Writes:** a `## Weekly Review` section to the weekly journal, covering: wins, stalls, surprises, cross-domain patterns, what to carry forward, what to consciously drop.

**Why this is a separate ritual from End of Week, not a section inside it:** End of Week is operational housekeeping; this is synthesis. Bolting synthesis onto the end of a housekeeping ritual puts the two in competition for the same five minutes of attention — and housekeeping always wins. Keeping them separate protects the thinking time.

## If a connector is down

Say so at the top of the output ("Calendar not reachable"), skip that source, and continue with what is available. Never silently produce a result that looks complete. Record the gap in the journal so the next run can catch up. If the vault itself is unreachable, produce the full output in chat so it can be pasted in later.
