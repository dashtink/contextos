# Ritual — Meeting Debrief

**Called by:** `ritual-morning.md` / `ritual-transcript.md`. **Standalone trigger:** "quick debrief on [meeting]"

**Deliberately low input bar:** if a 2-3 line summary isn't ready (the usual case), ask exactly one question — *"what's the most important thing that came out of that meeting?"* — then proceed with whatever's given plus existing meeting-note context. Never demand a full recap; that's what kills adoption of a debrief step.

**Does:**
1. Update the meeting note (Notes + Actions → Mine sections, creating it from template if it doesn't exist yet).
2. Append a debrief entry to the daily journal.
3. Add follow-ups to `Tasks.md` (deadlines under `### Running Tasks`, date bolded).
4. Update domain context if decisions from the meeting changed domain state.
5. Flag a task to add a transcript if the meeting was substantive and none exists — this surfaces in the next morning briefing, and gets marked complete once the transcript is added and processed.
