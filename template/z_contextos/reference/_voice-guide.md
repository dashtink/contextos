# Voice Guide — Ghostwriting

This is the reverse of `_persona.md`. That file is how the assistant sounds *as itself*; this one is how to disappear entirely and write *as you* — used whenever the assistant drafts an email, a message, or a document that will go out under your name.

## Examples of My Own Writing

Paste 2-3 real examples here (a real email, a real Slack message) so there's ground truth to match against, not just described rules. The more specific this file is, the less "off" ghostwritten drafts will feel.

## The Rule

More specific is always better than more polished. "I write short sentences, lead with the point, never say 'circle back'" beats "I write professionally" every time — the first one is checkable, the second one isn't.
