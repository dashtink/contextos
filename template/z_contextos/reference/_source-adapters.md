# Source Adapters

Rituals describe what to do with a source, not how to reach it. Pick the adapter that matches your stack and note it in the core file's Key IDs. If a source isn't connected, the ritual skips it and says so.

## Transcripts (`ritual-transcript.md`)
- **Pasted text:** default. Save the raw text to a file under `z_contextos/_data/Meeting-Notes/` or link it; the meeting note links to it, never contains it.
- **Gemini notes in Google Calendar/Meet:** notes arrive as an email; the transcript sits in the linked Drive doc's Transcript tab. Read the email subject and link, then the doc tab.
- **Otter / Zoom / Fireflies / Granola:** export or share the transcript as text or a doc, then treat as pasted text or a Drive doc.
- Never assign speakers from generic labels ("Speaker 1") unless unambiguous.

## Calendar, mail, chat
- Calendar: today's events with attendees. Mail: subject lines and senders, last 24h. Chat: date-filtered logs or exports, last work day.
- If a connector is missing, say which one and carry on.

## Tasks and tickets
- Default: `Daily/Tasks.md` only.
- Jira, Linear, Asana: read-only, date-filtered, only items assigned to or mentioned for the user. Do not mirror a tracker into the vault; link to it.
