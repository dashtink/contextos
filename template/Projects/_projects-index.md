# Projects — Roll-Up

A **Project** is work with a start, end, and deliverable, usually touching more than one domain. Test: *if it spans multiple domains and has a deadline and a deliverable, it's a Project; if it's ongoing subject-matter knowledge with no end date, it belongs in a Domain instead.*

| Project | Status | Target | Domains touched |
|---|---|---|---|
| [example-project] | not-started | [date] | [domain-a, domain-b] |

Closed status set: `active` · `at-risk` · `not-started` · `shipped` · `parked`.

On shipping: durable knowledge moves into the owning domain's `_context.md`, status is set to `shipped`, folder moves to `Projects/Complete/`.
